# yt-clip プライバシーポリシー

最終更新: 2026-09-25

## 集めていないもの

**yt-clip は利用者の情報を一切集めない。** 開発者を含め、誰かのサーバへ
データを送る経路を持たない。

- 閲覧履歴、視聴した動画、検索語を記録しない
- 個人を識別する情報を扱わない
- 利用状況の計測 (アナリティクス) を行わない
- 広告を出さない、広告事業者にデータを渡さない

## 端末の中に置くもの

| 置くもの | 場所 | 消えるとき |
|---|---|---|
| 設定 (投稿本文のテンプレート、チャンネルごとのハッシュタグ、クリップの最大秒数、モード、テロップの見た目) | `chrome.storage.sync` | 拡張を削除したとき |
| 窓 (操作のバー・区間とテロップの一覧・設定) の位置と大きさ、どの枠に入れたか | `chrome.storage.local` | 拡張を削除したとき |
| オン / オフ (全機能を止めているか) | `chrome.storage.local` | 拡張を削除したとき |
| 録画の進行状態 | `chrome.storage.session` | ブラウザを閉じたとき |
| 録画した動画 | ブラウザ内の IndexedDB | 投稿後に消える |

`chrome.storage.sync` に置いた設定は、利用者が Chrome の同期を有効にしている
場合に限り、**利用者自身の Google アカウント**を通じて利用者の端末間で同期される。
これは Chrome の機能であり、開発者はその内容を見られない。

`chrome.storage.local` に置いた窓の位置と大きさ・どの枠に入れたか・オン / オフは、その端末の中にだけ残り、同期されない。

## 録画した動画の行き先

録画は利用者のブラウザの中で完結する。

- **動画ファイルをディスクに書き出さない。** クリップはブラウザ内 (IndexedDB) に
  置かれ、投稿が済むと消える
- X へ添付するときも、動画は利用者のブラウザから X へ直接渡る
- 開発者のサーバは存在しない。経由する中継点は無い

## 求めている権限

| 権限 | 何のために |
|---|---|
| `storage` | 上表の設定・窓の位置と大きさとどの枠に入れたか・オン / オフ・進行状態を端末内に置くため |
| `https://www.youtube.com/*` | 再生画面に操作 UI を出し、選ばれた区間を録画するため |
| `https://x.com/*` | 投稿画面に動画と本文を入れるため。**投稿ボタンは押さない** |

## 第三者への提供

行わない。販売も、譲渡も、共有もしない。

## 子どもの利用について

年齢に関する情報を含め、いかなる個人情報も集めないため、
子どもから情報を集めることもない。
