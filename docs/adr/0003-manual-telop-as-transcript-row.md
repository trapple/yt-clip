# 0003. 手入力のテロップは文字起こしの欄の行にする

- 状態: 採用 (2026-11-03)
- 補うもの: ADR 0001 の Consequences「喋りの無い動画のために、時間で区間を作る道とテロップを手で足す道を脇に残す」

## Context

段階 1c-2 で区間の一覧とテロップの一覧を外す。外した後も、字幕の無い動画や、欄の行に無い文言 (補足・ツッコミ) の
テロップを足す道が要る。

## Decision

- 文字起こしの欄に「＋ ここに字幕を足す」を置き、今の再生位置に手入力の行を作る。行は字幕の行と同じ並びに入り、
  ✎ で文字を直す (回答 2026-11-03「欄に手入力の行を足す (推奨)」)
- 手入力の行の時刻は、その行の「頭を今に」「尻を今に」で直す (回答 2026-11-03「行に「頭を今に / 尻を今に」 (推奨)」)。
  はじめに「時刻は詰める欄で直す」としたが、詰める欄が直せるのは区間の頭と尻だけで、テロップの時刻を直す帯は
  1c-2 で外す。詰める欄にテロップを詰める状態を足すと、欄が「区間を詰める」と「テロップを詰める」の 2 通りになり
  変更が大きい
- 区間は IN / OUT と ＋ 区間を追加で作る (時間で区間を作る道)

## Considered Options

- 詰める欄にテロップの帯を置き、＋ テロップもそこに置く: 今の帯の制約 (2 段まで・+N・窓の中だけ) が残る
- 1c-2 の計画のときに決める: 一覧を外す前に置き場所を決めておかないと、1c-1 の詰める欄の作りが決まらない

## Consequences

- テロップの置き場所が欄の 1 か所にまとまる。手入力のテロップも ✎・字幕に出さない・▶ が字幕の行と同じになる
- 手入力の行は文字起こしを取り直しても消えない形で持つ必要がある。**`lineId` の無いテロップそのものを行にする**
  (回答 2026-11-03「テロップそのものを行に (推奨)」)。テロップは文字起こしとは別に clip に持ち、行を外して消えるのは
  `lineId` が合うテロップだけなので、取り直しても残る。保存先は増やさない
  - 寿命はクリップと同じ。IN で作り直すと、行から作ったテロップと一緒に消える
  - テロップは区間が 1 つ以上あるときしか持てない (0 個で idle に戻る)。区間が無いと「＋ ここに字幕を足す」は押せず、
    字幕の無い動画では IN / OUT で区間を作ってから足す
  - 退けた案: 手入力の行を動画ごとに別に保存する。IN で作り直しても残るが、保存の形・取り直したときの混ぜ方・消し方を
    新しく作ることになる
