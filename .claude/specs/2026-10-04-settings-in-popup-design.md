# 設定を popup へ移す

依頼 (2026-10-04、逐語):

> 設定系を全部ツールバー（画像）のほうにおく

「ツールバー (画像)」= ツールバーの拡張アイコンを押すと出る popup (`src/popup/`。今はオン / オフのスイッチと状態の文言だけ)。
「設定系」= 今バーの **⚙** で開く設定パネル (`SETTINGS_FIELDS` の全項目: モード・最大秒数・チャンネル別ハッシュタグ・
テロップの見た目 5 項目)。

---

## 1. 何が変わるか

| | 今 | 後 |
|---|---|---|
| 設定を開く場所 | バーの右端の ⚙ → 設定の窓 (ドックの設定タブ / 浮いた窓) | **popup に常に出ている** (開閉は無い) |
| ページの窓 | バー / 区間・テロップ / 設定 の 3 つ | **バー / 区間・テロップ の 2 つ** |
| ⚙ ボタン | バーの右端 | **無くす** |
| 項目・保存の仕方 | 「保存」ボタンでまとめて書く。1 つでも通らなければ何も書かない | **変えない** (`SETTINGS_FIELDS` をそのまま並べる) |
| 保存先 | `chrome.storage.sync` の `settings` | **変えない** (ページ側は今までどおり `onChanged` で拾って反映する) |
| 保存した後 | 「保存しました」と正規化した値を出し、開いたまま | **popup を閉じる** (依頼 2026-10-05「保存ボタンおしたら閉じて欲しい」)。通らない項目があったとき・書けなかったときは閉じずに理由を出す |

popup の並び:

```
[●] yt-clip を使う
    この端末だけに効く (同期しない)
──────────────────────────────
0:21 〜 0:36 (15秒) を録画できます      ← 状態 (変えない)
──────────────────────────────
設定
 モード            [シンプル ▾]
 最大秒数          [60        ]
 ハッシュタグ       [#切り抜き  ]
   @handle のチャンネルに付ける
 …テロップ 5 項目…
                                   [保存]   ← 書けたら popup を閉じる
```

- **保存できたら popup を閉じる** (`window.close()`)。閉じるのは書き込みが済んでから (閉じると popup の処理ごと止まるので、
  書き終える前に閉じない)。**閉じない**のは、通らない項目があったとき (何も書かずに理由を出す) と書き込みが失敗したとき
  (理由を出す)。どちらも直してもう一度押せるように開いたままにする。正規化した値 (`#` 付き・重複なし) は、次に開いたときに
  入力欄で見える
- **設定はオン / オフに関わらず出す** (sync の設定はページの有無と無関係。オフの間に設定を直してからオンに戻せる)
- 状態を取得できなかったとき (service worker が居ない) も設定は出す (`chrome.storage` へ直接読み書きする)

## 2. チャンネル別ハッシュタグの文脈

ハッシュタグは「いま開いている動画のチャンネル」に付く (`scope: "channel"`)。popup はページの DOM を読めないので、
**アクティブなタブの content script に問い合わせる**:

- popup → content (YouTube): `chrome.tabs.query({ active: true, currentWindow: true })` で得たタブへ
  `chrome.tabs.sendMessage(tabId, { type: "channel/get" })`。応答は `{ channel: Channel | null }`
- **権限は増やさない。** `tabs.query` は `tabs` 権限なしでもタブの id を返し、`tabs.sendMessage` は content script が
  居るタブ (= ホスト権限のある YouTube) にだけ届く
- content は**動作中 (オン) で動画の再生画面にいるときだけ** `getChannel()` を返す。ID が取れなければ null
  (今の `readChannelContext` と同じ)
- 次のときは **channel = null** として扱う (ハッシュタグ欄は今の「特定できない」と同じく入力不可で、理由の文言を出す):
  YouTube 以外のタブ・受け手が居ない (オフ / 読み込み前 / 拡張を更新した後で読み込み直していない) ・動画ページ以外・
  **1 秒で応答が無い** (待ち続けない)
- 問い合わせは popup を開いたときに 1 回。**保存時は開いたときの文脈を使う** (popup を開いている間はタブを移れないので、
  開き直しのたびに読めば足りる)

## 3. ページ側から外すもの

- ⚙ ボタン・`settingsPanel`・設定の窓 (`yt-clip-settings`)・`onToggleSettings`・モード切り替え時の「開いていた設定を開き直す」処理
- 窓の名前 `WindowId` から `"settings"` を除く (`"bar" | "list"`)。最初の配置の右の枠は `["list"]` だけになる
- `initialSettingsRect` / `SETTINGS_CASCADE_PX` (設定の窓の最初の位置)
- **覚えた配置 (`chrome.storage.local` の `windowLayout`) に `"settings"` が残っていても警告しない。** 前の版が書いた
  正しい値なので、`docks.*.tabs` の `"settings"` と `float.settings` は**黙って捨てる** (知らない窓として warn すると、
  更新しただけで毎回コンソールに出る)。書き戻しは次に窓を動かしたときに自然に起きる

## 4. 作り

- 設定フォーム: `src/content/settings-panel.ts` を `src/popup/settings-form.ts` へ移す。開閉 (`toggle`) を無くし、
  `createSettingsForm(deps)` が `{ element, fill() }` を返す。項目を並べる・保存の差分・正規化の表示はそのまま
- 見た目: 配色はページ内の窓と同じ `--ytc-*`。popup.ts が `applyPalette(document.body, isDarkTheme())` で置く
  (popup にページのテーマは無いので OS の設定に従う)。`PANEL_STYLE` は popup 専用になるので `settings-form.ts` の
  `FORM_STYLE` へ移し、**popup の高さの上限 (Chrome は 600px) に寄せて詰める**: 項目名と入力欄を横に並べ、説明は下に
  小さく出す。「保存」は下端に貼り付ける (sticky。上限を超えてスクロールしても押す場所を探させない)
- popup の幅は 320px → **380px** (項目名と入力欄を横に並べるため。8 項目で高さ約 615px)
- メッセージ: `Message` に `{ type: "channel/get" }` を足す。応答の型 `ChannelResponse = { channel: Channel | null }`
- ついでに直す: popup の進捗バーの箱 (`#progress-area`) は CSS の `display:flex` が UA の `[hidden]` に勝ち、録画中以外も
  空の進捗バーが出ていた。`[hidden]` のときの `display:none` を明示する

## 5. 受け入れ条件

- YouTube の動画ページにバーの ⚙ が無く、設定の窓・設定タブがどこにも出ない
- popup に全項目が出て、保存すると YouTube のページに反映される (モード・テロップの見た目・最大秒数)
- 動画ページで popup を開くと、ハッシュタグ欄にそのチャンネルのタグが入っていて、保存できる
- YouTube 以外のタブ・オフのときは、ハッシュタグ欄が入力不可で、ほかの項目は保存できる
- 前の版で覚えた配置 (`"settings"` を含む) を読んでも warn が出ず、バーと区間・テロップの窓は覚えた場所に出る

## 検討した選択肢

- **popup にチャンネル別タグを出さず、ページに残す** — 「全部」に反する。不採用
- **チャンネルを service worker 経由で取る** (状態機械の `clip.meta.channelId`) — クリップが無いと取れず、別の動画を
  開いていると違うチャンネルになる。不採用
- **オプションページ (`options_ui`) に置く** — 依頼は「ツールバー (の popup)」。不採用
