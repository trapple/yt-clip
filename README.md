# yt-clip

YouTube の切り抜きを作って X に投稿する Chrome 拡張機能 (MV3)。

視聴中に IN を押すと既定 15 秒の範囲ができ、詰める欄で調整してから録画すると、
再生中の動画そのものを直接録画して動画ファイルを作り、X の投稿画面に本文
つきで自動添付する。外部ツール (yt-dlp / ffmpeg) のインストールは不要。

## 使い方

1. YouTube の再生画面で切り抜きたい場面の頭で **IN** を押す（15 秒の範囲ができる）
2. プレイヤー下の **詰める欄** でハンドルをドラッグして範囲を調整する (区間の前後 2 秒が見える)。
   トラックを押すとその位置から再生でき、**▶ 区間を見る** で通しの確認もできる
3. **● 録画** を押す（録画は実時間かかる。途中で **■ 中止** できる）
4. プレビューで確認し、**X に投稿** を押す
5. 開いた投稿画面で内容を確認して自分で投稿する

操作は YouTube のページ内で完結する。設定はツールバーの拡張アイコン (popup) で変える。

IN / OUT・録画のボタンと詰める欄 (以下まとめて「バー」)、文字起こしの欄 (区間の見出しとテロップもここに出る) は、2 つの窓 (**バー** / **区間・テロップ**) に出る。
**最初はページの中に入っている**: バーはプレイヤーの直下、区間・テロップはおすすめ動画の上に入り、ページと一緒に
スクロールする。区間・テロップの窓は動画ページでいつも出る (先頭に文字起こしの欄があるため)。

窓は浮かせて好きな場所に置ける。タブ (プレイヤーの下にバーだけのときは ⠿) を掴んで外へ引き出すと、浮いた窓になる。
浮いた窓は ⠿ や見出しを掴んで動かせ、右下の角をドラッグすると大きさが変わる (バーは幅だけ)。ドラッグしている間、
プレイヤーの下とおすすめ動画の上に点線の帯 (落とし先) が出て、帯の中で離すとページの中に戻る。同じ場所に 2 つ以上
入れるとタブになる。置いた場所と大きさは、次に開いたときも同じになる。**⠿・見出し・タブをダブルクリックすると最初の配置
(ページの中) に戻る。**

投稿ボタンは自動では押さない。最終確認は必ず手元に残る。

**ツールバーの拡張アイコン (popup) のスイッチで、全機能をオフにできる。** オフの間は YouTube と X のページに何も出さず、
何も変えない (この端末だけ。同期しない)。オンに戻すと、開いているタブでもそのまま戻る。アイコンに `OFF` のバッジが出る。

## 文字起こしの欄

区間・テロップの窓の先頭に、動画の公式字幕を発話の行にしたもの (文字起こし) が出る。行を選ぶと区間になり、
行の文字がそのままテロップになる。テロップの時刻は行の時刻を使うので、出す時間を合わせなくてよい。

- **行を押す** — その行を区間に入れる / 外す。続いた行は 1 つの区間になる (頭は行の 0.2 秒前、尻は 0.3 秒後まで)。
  途中の行を外すと区間が 2 つに割れる
- **Shift + 行を押す** — 直前に押した行からこの行までをまとめて入れる / 外す
- **区間に入った行の ✎** — テロップの文字を直す (Enter で確定、Esc で戻す、Shift + Enter で改行)
- **字幕に出さない** — 区間には残し、テロップだけ出さない (相づちなど)。もう一度押すと出す
- **行の時刻を押す** — その行の頭から再生する。再生中の行には ▶ が付く (録画中は動かさない)
- **区間の見出し** — 区間の頭の行の上に「区間 1」と頭と尻 (100 分の 1 秒まで)・長さが出る。押すとその区間を詰める欄で
  詰める (見出しに「· 詰めている」が付く)。**✕** でその区間を消す
- **＋ ここに字幕を足す** — 今の再生位置から 3 秒のテロップ (手入力の行) を足し、文字を打つ欄を開く (Enter で確定)。
  手入力の行は字幕の行と同じ並びに、点線の印付きで入る。✎ で文字を直し、**頭を今に / 尻を今に** で出す時間を今の
  再生位置に合わせ、時刻を押すと頭から再生し、✕ で消す。区間が無いときは押せない (先に行を押すか IN / OUT で区間を作る)。
  文字起こしを取り直して行が無くなったテロップも、消えずに手入力の行として出る (要らなければ ✕ で消す)

**区間に入っている字幕の行は、どう区間に入れても行の文字がテロップになる**。行を押したときだけでなく、詰める欄のハンドル・
±0.1・IN / OUT・＋ 区間を追加で区間を広げて行が (半分以上) 入ったときも同じ。区間から外れた行のテロップは消える。直した文字は
この動画の間だけ覚えていて、また入ると戻る。要らない行は「字幕に出さない」にする

**行を押した・手入力の行や見出しを操作した答えが返るまでは、もう一方の操作を受けない** (「前の操作の答えを待っています」と出る。
行の入れ外しは区間とテロップを丸ごと差し替えて送り、手入力の行と見出しの ✕ はテロップや区間を位置で指して送るので、答えを待たずに
混ぜると、別のテロップを書き換えたり、直した文字を古い写しで戻したりする)。

行と行の間が 3 秒より空いていれば、続けて選んでも別の区間になる (曲や沈黙を挟まない)。1 秒に満たない区間は前後へ
広げて 1 秒にする。1 つの区間が上限の秒数 (設定、既定 60 秒) を超えるときは入れずに理由を出す。
**＋ 区間を追加や IN / OUT で作った区間は、欄で押した行に当たらなければ変わらない**。当たれば、その行の分だけ
伸びる・切り取られる。

文字起こしは YouTube の公式字幕 (手動の字幕があればそれ、無ければ自動字幕) から取る。取れるまで数秒かかる。
保存しきれない長さ (2 時間を超える配信など) の文字起こしは保存せず、開くたびに取る。
字幕の無い動画では、IN / OUT や ＋ 区間を追加で区間を作り、＋ ここに字幕を足す でテロップを足す (欄には区間の見出しと
手入力の行だけが並ぶ)。
**吹き替えの音声が流れている動画では、欄にそのことを出す** (字幕は元の音声のものなので、録画の音と合わないことがある)。

## 詰める欄

バーの上の方が「詰める欄」になる。選んでいる区間 (文字起こしの欄で押した行か区間の見出しの区間) の
前後 2 秒までを映し、頭と尻を細かく詰める。

- **見出しの行** — 「区間 2 を詰める」と、区間の頭と尻 (100 分の 1 秒まで)・長さ・全区間の合計と上限 (「合計 24.6 / 60 秒」。上限を超えると警告色)。**‹ 区間 1 / 区間 3 ›** で前後の
  区間へ移る。詰める操作 (下の ±0.1 と ▶) も同じ行にある
- **ハンドル** — ドラッグで頭と尻を動かす。**文字起こしの単語の切れ目に吸い付く** (近くに切れ目があるとき)。**Alt を押している間は
  吸い付かない**。手を離すと、新しい区間の前後 2 秒を映し直す (もっと伸ばしたいときは、もう一度端まで引く)
- **単語の並び** — トラックの下に、映している範囲の単語を並べる (区間の外の単語は点線)。自動字幕は単語ごと、手動字幕は行ごと
- **頭 −0.1 / ＋0.1・尻 −0.1 / ＋0.1** — 0.1 秒ずつ動かし、動かした端の映像を出す。**キーは `,` (−0.1) と `.` (＋0.1)** で、最後に
  掴んだ (または ±0.1 を押した) 端を動かす。はじめは頭。キーで動く方の「頭」「尻」に下線が付く。キーが効くのは詰める欄の
  ハンドルかボタンを触った後だけ (YouTube の `,` `.` (コマ送り) と取り合わないため)。**前に動かした分の答えが返るまでは、次の
  ±0.1 は受けない** (押し続けても、答えの来ない間の分は数えない。答えを待たずに積むと、届いた答えで区間が巻き戻り、隣の区間を
  書き換えることがあるため)
- **▶ 頭** — 頭の 2 秒前から頭の 2 秒後まで再生して止める。**▶ 尻** — 尻の 2 秒前から尻の 2 秒後まで再生して止める (切り落とした
  所も聞こえる)

録画中と、録画した後のプレビューの間は、詰める欄は薄く出て動かせない。

## 複数の場面を繋ぐ

同じ動画の中の複数箇所を拾って 1 本に繋げられる。区間が 1 つなら、上の「使い方」のとおり 1 つの範囲を切り抜く。

- **＋ 区間を追加** — 今の再生位置から新しい区間を作り、それを選ぶ
- **IN** — 区間が 1 つでテロップが無いときは、今の位置から範囲を作り直す (これまでのシンプルと同じ)。区間が 2 つ以上か
  テロップがあるときは、選んでいる区間 (詰める欄の区間) の頭を今の位置に合わせる。録画した後 (プレビュー・添付に失敗した後) に
  作り直すときは、消える区間とテロップの数を出して、もう一度 IN を押したら作り直す
- **OUT** — 選んでいる区間の尻を今の位置に合わせる

欄の区間の見出しや詰める欄の ‹ › で区間を選ぶと、詰める欄がその区間に切り替わる。録画は区間を順に辿って 1 本のクリップにする。

区間の見出しは、区間・テロップの窓 (最初はおすすめ動画の上) の文字起こしの欄に出る。IN / OUT・録画のボタンと詰める欄は
最初はプレイヤーの直下に出るので、区間が増えてもページをスクロールせずに操作できる。

### テロップ

テロップは文字起こしの欄で作る。字幕の行を区間に入れるとその行の文字がテロップになり、行に無い文言 (補足・ツッコミ) は
**＋ ここに字幕を足す** で手入力の行として足す (上の「文字起こしの欄」)。

テロップはプレイヤーの上に、録画と同じ見た目で重なって見える。録画すると
動画に焼き込まれる。見た目 (文字サイズ・フォント・文字の色・縁取りの色・
縁取りの太さ) は popup の設定で決める。全テロップ共通。


## 仕様と制約

使う前に知っておくと驚かないこと。**できないことだけでなく、そう作った理由も
書いてある。**

### 録画

- **録画は実時間かかる**。動画そのものを `captureStream()` で録画する方式の
  ため、30 秒のクリップを作るには 30 秒待つ必要がある (倍速での録画は
  できない。倍速再生すると早送り映像がそのまま記録されてしまうため、
  等速固定にしている)
- **画質は録画時に再生している画質になる**。`captureStream()` が返すのは
  デコード済みのフレームなので、360p で再生しながら録れば 360p のクリップに
  なる。録画してから画質を上げることはできないため、720p 未満で録画を始めると
  警告を出す (録画自体は止めない)
  テロップ付きの録画は、録画開始時の画質で固定される (途中で画質が上がっても出力の解像度は変わらない)
- **クリップの最大長は既定 60 秒**。popup の設定から 1〜140 秒の範囲で変えられる
  (上限の 140 秒は X の動画の上限に合わせている)。超える範囲は録画に進めない
- **DRM 保護された動画 (有料レンタルなど) は録画できない**
- **録画中に広告が挟まると中断される**。広告の映像が切り抜きに混入するのを
  避けるため
- **MP4 で録画できない環境では投稿まで進めない**。ブラウザが
  `video/mp4;codecs="avc1.640028,mp4a.40.2"` に対応していない場合 (プロプライエタリ
  コーデック無しの Linux Chromium など)、X に添付できる形式で録れないため
  行き止まりになる。macOS / Windows の Chrome では起きない

### 区間の結合

- **結合できるのは同じ動画の中だけ**。別の動画の切り抜きは繋げられない
- **区間は動画の時間順に繋がる**。後から前の場面を足しても、時間順の位置に入る
- **重なった区間はそのまま残る**。同じ場面を 2 回入れられる。ただし録画中に
  巻き戻しシークが入るぶん、待ち時間は伸びる。
  文字起こしの欄で、重なった区間の隣の行を足して繋ぐときは、繋がる区間を 1 つにまとめる。
- **最大長は合計で見る**。区間ごとではないので、20 秒の区間を 4 つ作ると
  既定の 60 秒を超えて録画に進めない
- **録画にかかる実時間は合計長 + 区間の間のシーク**。区間が増えるほど
  待ち時間も伸びる

### テロップの制約

- **テロップの時刻は元動画の時刻に付いている**。区間を並べ替えたり縮めたりしても、
  テロップはその場面の発話に付いてくる。同じ場面を 2 回使えば、テロップも 2 回出る
- **どの区間にも入らないテロップは録画に出ない**。手入力の行に「(区間外)」と出る。
  消さずに残るので、区間を伸ばせば出るようになる
- **位置は画面下の中央に固定**。複数が同時に出るときは作った順に下から積む
- **画面の幅に収まらない行は、自動で折り返す** (左右に動画の幅の 5% ずつ空ける)。日本語は文字の間で、英語は単語の間で
  折り返し、句読点や閉じ括弧が行の頭に来ないようにする (その 1 文字だけ右へはみ出すことがある)。改行を入れた所はそのまま
  改行になる。折り返して行が増え、画面の上にはみ出した行は描かない (下の項目)
- **1 つのテロップは 500 文字まで**。長い文言は分けて入れる。画面の上にはみ出した行は描かない
- **フォントは環境によって字形が変わる**。プリセット (ゴシック / 明朝 / 丸ゴシック)
  は Mac / Windows の標準フォントを順に探す。名前を書いたフォントが手元に無いときは
  代わりのフォントで描かれる (popup で保存した瞬間のプレビューで分かる)
- **テロップ付きの録画は、録画開始時の画質で固定される**。録画中に画質が上がっても
  出力の解像度は変わらない。録画中に popup でテロップの見た目を変えても、その録画には効かない
- **テロップ付きの録画中はタブを離れられない**。タブが隠れると中断する (隠れたタブでは合成した映像が止まり、音声だけ進むクリップになるため)。「もう一度」で区間もテロップも残ったまま録り直せる
- **手入力の行か、直した (字幕に出さないにした) 行のテロップが残っている間は、最後の 1 区間を消せない**。区間と一緒に手入力の
  文言が全部消えるのを防ぐため。先にテロップを消す (直していない行のテロップは、行を入れ直せばまた作れるので止めない)
- **手入力の行はクリップと一緒に消える**。IN で範囲を作り直すと、行から作ったテロップと一緒に消える (文字起こしを
  取り直しても消えない)。出す時間は「頭を今に / 尻を今に」で合わせる (詰める欄で詰めるのは区間の頭と尻だけ)

### 投稿本文

- **ハッシュタグを入れられる**。動画を開いたタブで popup を開き、設定から入れる。`#` は省略でき、
  空白・全角空白・読点で区切る。設定は投稿のたびに読み直されるため、
  タグを変えて「X にもう一度投稿」すれば録り直さずに反映される
- **ハッシュタグはチャンネルごとに持つ**。共通のタグは無い。鍵にはチャンネルの
  ハンドル (`@name`) を使うため、**チャンネルがハンドルを変えるとタグは
  引けなくなる** (設定し直せば戻る)。ハンドルを読めない画面・YouTube の動画以外のタブ・オフの間は、
  ハッシュタグ欄だけ入力できない (popup はいま開いているタブにチャンネルを問い合わせる)
- **X への投稿はログイン済みアカウントが前提**。ログイン状態やアカウントの
  切り替えまでは拡張側では関知しない

### クリップの置き場所

- **動画ファイルをディスクに書き出さない**。録画したクリップはブラウザの中
  (IndexedDB) に置かれ、X の投稿画面へ添付されるだけで、`~/Downloads` などの
  ファイルシステムには保存されない
- **投稿した後も範囲とクリップは残る**。同じクリップをもう一度投稿でき、
  範囲を変えれば録り直せる。範囲を変えた時点でクリップは外れる (古い範囲の
  クリップを持ち続けると、画面に出ている範囲と投稿される中身が食い違うため)
- **X への添付が失敗してもクリップは捨てない**。録画は実時間のコストを払った
  成果物なので、投稿画面の DOM 変更等で自動添付に失敗しても保持し、
  「X にもう一度投稿」でやり直せる状態に留める

### 操作の置き場所

- **切り抜きの操作は YouTube のページ内で完結する**。ポップアップが持つのはオン / オフのスイッチ (ページに何も無いときに
  オンへ戻すため。どの状態でも押せる) と設定だけ。状態も映す (YouTube 以外のタブにいるときに状態を見る場所が無くなるため)
- **設定はすべてポップアップにある** (ページには ⚙ も設定の窓も無い)。オフの間も変えられる。「保存」で書いて popup が閉じ、ページには
  すぐ反映される (入力に誤りがあると閉じずに理由が出る)
- **区間の見出しとテロップは、区間・テロップの窓の文字起こしの欄に出る**。最初はバーがプレイヤーの直下、区間・テロップが
  おすすめ動画の上に入っている (ページの中なので動画を隠さない)。詰める欄は幅がそのまま精度になるため、区間・テロップの
  窓の幅には縮めない
- **ページの中に入れられる場所は 2 か所** (プレイヤーの下・右の列のおすすめ動画の上)。入れた窓はページと一緒にスクロール
  し、動画に重ならない。同じ場所に 2 つ以上入れるとタブになる (並びは入れた順。並べ替えは一度引き出して入れ直す)
- **バーはおすすめ動画の上には入れられない** (最小の幅 480px が右の列より広い。拡大バーは幅がそのまま精度になる)
- **落とし先は画面に見えている帯だけ**。ドラッグの間にページは自動でスクロールしない (コメント欄まで送っているときは、
  先に上へ戻す)。浮いた窓を少し動かしただけでは入らない (ドラッグを始めた所から 40px 以上離れ、帯の外から入った
  ときだけ入る)。タブは 8px 以上ドラッグすると抜ける (押して離しただけなら、そのタブが前に出る)
- **シアターモードでは、右の列に入れた窓は動画の下へ回る** (自動では浮いた窓に戻さない。YouTube のレイアウトに依存した
  判定で窓が勝手に跳ばないように)。動画を見ながら触りたいときはタブを引き出す。浮かせた区間・テロップの窓は
  動画の右側に重なりうるので、そのときは見出しを掴んで動かすか、ページの中に入れる
- **1 列表示などで入れた場所が無い間は、その窓を浮いた窓で出す** (浮いた窓の最初の位置に出す。入れた場所は覚えたままで、
  場所が戻れば戻る。その間に動かすと浮いた窓になる)
- **ページの中に入れた窓が画面の外にあるときに区間・テロップを足しても、結果は見えない** (その窓の
  タブが前に出るだけで、ページは自動で動かさない。スクロールして戻す)
- **プレイヤーの下にバーと一緒にほかの窓を入れると、1440x795 などの画面では 1 画面に収まらない** (タブの列の分だけ背が
  高くなる。バーだけなら収まる)。ページの中なのでスクロールすれば届く
- **窓は畳めない**。重なるときは動かすか、ページの中に入れる (畳んだ状態と重なり順とタブの組み合わせを増やさないため)
- **全画面の間と、動画の再生画面以外では、どの窓も出さない**
- **YouTube の中のどのページ (ホーム・検索結果・チャンネルなど) から動画を開いても出る**。YouTube の中の移動はページを
  読み込み直さないので、拡張は YouTube のどのページでも読み込まれ、動画の再生画面になったところで窓と枠を出す。
  **動画の再生画面以外ではページに何も差さない** (窓・ドック枠・シークバーの帯・プレイヤーの上のテロップを外す。動画へ戻れば
  同じ位置・同じ枠に出る)
- **拡張を更新・読み込み直した後は、開いていた YouTube のタブを読み込み直す** (Chrome は開いているタブへ拡張を入れ直さない)
- **状態の文言は 1 行に収める**。長い文言は末尾が「…」で省略され、マウスを乗せると全文が出る
- **浮いた窓は動かせる**。区間・テロップの窓は見出し、バーは操作の行の左端の ⠿ を掴んで動かし、右下の角で
  大きさを変える。**バーは幅だけ変えられる** (高さは中身で決まる。拡大バーは幅がそのまま精度になる)。
  最小はバーが幅 480px、区間・テロップの窓が幅 280px・高さ 160px。最大は画面の大きさまで。バーに見出しの行を
  付けないのは、そのぶん背が高くなると狭い画面 (1440x795 など) でプレイヤーの下端を覆うため。詰める欄も、見出しと詰める操作を
  1 行にまとめて背を抑えている。テロップの帯の段を外したので、**1440x795 でもページの中のバーは画面に収まる** (詰める欄の見出しの
  行が折り返すほど狭い窓では背が伸びる)。浮かせたバーはプレイヤーの下端に重なることがある (浮いた窓は動画の上にも置ける)
- **置いた位置・大きさ・入れた場所 (タブの並びと前のタブ) は端末ごとに覚える** (`chrome.storage.local`。Chrome の同期で
  他の端末へは運ばない。画面の大きさと置き場所の好みは端末ごとに違うため)。**掴む場所 (⠿ / 見出し / タブ) をダブルクリック
  すると最初の配置 (ページの中) に戻り、覚えた位置も消える**。同じ端末で YouTube のタブを複数開いているときは、**最後に窓を
  動かした (戻した・入れた) タブの配置が残る** (別のタブで動かした位置は、こちらのタブで窓を動かすと上書きされる)
- **窓は見失わない**。画面の外へドラッグしても、ブラウザを小さくしても、浮いた窓の掴む場所 (バーは ⠿、ほかの窓は見出し) は
  画面の中の、YouTube のヘッダーより下に残る。大きい画面で覚えた位置を小さい画面で開いたときも同じ
- **動かしていない浮いた窓 (入れた場所が無い間に浮いている窓など) は、ブラウザの大きさやプレイヤーの大きさ (シアターモードの
  切り替えなど) が変わると最初の位置を取り直す** (プレイヤーが画面の上へスクロールされて見えないときは、バーは YouTube の
  ヘッダーの直下に出る)。ページをスクロールしても浮いた窓は同じ画面位置に浮いたまま (コメント欄を読む間も操作できる)。
  動かした窓は置いた場所から動かない
- **画面の高さが足りないとき、浮いたバーは画面の下端 (から 16px) に寄せて出す**。そのときだけプレイヤーの下端に重なる
  (プレイヤーの下に入れれば重ならない)
- **浮いた窓が重なったときは、触った順が新しいほど上に出る** (直前に触った窓が、その前に触った窓の下に潜らない)

### オン / オフ

- **オフの間は YouTube と X のページに何も出さず、何も変えない**。窓・ドック枠・シークバーの帯・プレイヤーの上のテロップが
  消え、ページのイベントも監視しない。拡張の中に残るのは、オン / オフを読む処理と、変わるのを待つ処理だけ
  (ページからは見えない)
- **オン / オフはこの端末だけに効く** (`chrome.storage.local`。Chrome の同期で他の端末へは運ばない。「いま、この端末で
  止めたい」ための操作なので)。同じ端末で開いている YouTube のタブは、すべて同時に切り替わる
- **オンに戻すと、開いているタブでも読み込み直さずに戻る**。オフにしても、作った区間・録画済みのクリップ・窓の配置・
  設定は消えない
- **録画中にオフにすると録画は中止される** (■ 中止と同じ。区間とテロップは残り、オンに戻すとそのまま録り直せる)
- **書き出し中にオフにすると、書き出しが済んでから消える** (数秒。録れたクリップは残り、オンに戻すとプレビューから続く)
- **X の投稿画面が開いている間にオフにすると、添付は進まず 30 秒ほどで「X にもう一度投稿」に落ちる** (クリップは残る。
  落ちないときはオンに戻したバーの「取り直す」で抜ける)
- **オフにした後も popup に「録画を中止しています…」「書き出しが済んだら止まります…」が出たまま変わらないとき**
  (録画していたタブをその間に読み込み直した、など) は、オンに戻すか、そのタブを閉じると抜ける

## 開発

```bash
npm install
npm run build      # dist/ に拡張を出力
npm test           # 単体テスト
npm run typecheck  # 型チェック
npm run e2e        # E2E (ネットワーク必須。CI では実行しない)
npm run check:telop # テロップの実機確認 (Google Chrome が開く。結果は test-results/telop-check/)
npm run icons      # アイコンを描き直す (public/icons/)
npm run screenshots # 掲載用スクリーンショットを release/screenshots/ に撮る
npm run package    # ウェブストアへ上げる zip を release/ に作る
npm version patch  # 版を上げる (型チェックとテストが通ってからコミットとタグ)
```

版番号の出どころは `package.json` の 1 箇所だけ。`manifest.config.ts` は
それを読むので**手で直さない**。変更履歴は [`CHANGELOG.md`](CHANGELOG.md)。

ウェブストアへの公開手順は [`docs/store-release.md`](docs/store-release.md)。
**審査に落ちる可能性が高い理由もそこに書いてある。先に読むこと。**

### E2E が失敗したときの切り分け

E2E は実際の YouTube を開くため、実装とは無関係な理由でも落ちる。失敗したら
`test-results/` に残る trace・スクリーンショット・動画をまず見ること。

| 症状 | 原因の候補 |
|---|---|
| service worker が現れない | `dist/` が未ビルド、または manifest のパス誤り |
| `#yt-clip-bar` が出ない | `YT_SELECTORS.mountAnchor` (`#below`。バーはもうここには置かないが、動画ページができたかの目印に見ている) が YouTube の DOM 変更で不一致 |
| IN を押しても範囲が確定しない | 動画タイトルの読み込みが間に合っていない、または `YT_SELECTORS.title` の不一致。広告や同意ダイアログがクリックを奪っている可能性もある |
| status の文言が違う | `formatTime` の出力、または `validateRange` で弾かれている |
| 録画が preview まで進まない | DRM 保護された動画、MP4 非対応 (この場合は degraded の文言になる)、または広告の混入 |

`chrome://extensions` でデベロッパーモードを有効にし、`dist/` を
「パッケージ化されていない拡張機能」として読み込む。

E2E は実ネットワークと YouTube の実 DOM に依存するため CI では実行せず、
リリース前のローカル確認に使う。X への添付はログイン済みアカウントを
要するため自動化しておらず、[`docs/manual-check.md`](docs/manual-check.md)
のチェックリストで手動確認する。
